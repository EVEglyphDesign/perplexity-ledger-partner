## Numbering

This repository uses [APQC Process Classification Framework](https://www.apqc.org/process-frameworks)
dotted-decimal numbering, rooted at two categories:

- **11.0 Manage Sustainability** — the load-bearing ESG / Truth Ledger stream
- **12.0 Manage External Relationships** — the partner-arrangement mechanics

Downstream depth is `category.process-group.process.activity.task` — e.g.
`12.1.1-front-end-contract`. A commit at any depth cites its immediate parent in
its first line.
