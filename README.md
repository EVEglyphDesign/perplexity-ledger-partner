# perplexity-ledger-partner

Public framing repository for the proposed EVEglyphDesign × Perplexity channel-partner
arrangement. Positions Perplexity as the front-end for the EVEglyphDesign eDiscovery
framework, paired with Truth Ledger wobble-control so a share of every deployment lands
at cost in the nonprofit caring sector.

**Status.** Framework draft. Nothing here binds Epiq or Perplexity.
**Prior claim.** Epiq holds first-writer refusal on the eDiscovery framework and is
being given the chance to adopt it before any external channel is engaged.
**US deployment.** Any US-side execution routes through the Jeff Eden entity under
EgD-KC-001 first right of refusal.

## Layout

| Folder | Purpose |
|---|---|
| [`.canon/`](.canon/) | The Perplexity-specific canon that governs this repository |
| [`00-blueprint/`](00-blueprint/) | Design intent, arrangement shape, ESG frame, gap statement |
| [`10-technical/`](10-technical/) | Interface specs, ledger integration, front-end contract |
| [`20-execution/`](20-execution/) | Proposal, statements of work, sequencing |
| [`30-tracking/`](30-tracking/) | Trackable spreadsheets that hang off the specs |
| [`foundation/`](foundation/) | Perplexity's own public statements, quoted verbatim |

The numbering is the operating principle: **blueprint (00) precedes technical (10)
precedes execution (20), and tracking (30) hangs off the specs.** A change to a `10-`
document may not land without the matching `00-` intent already committed. A `20-`
artifact may not commit without its `10-` reference. `30-` is the shared read-only
surface that a phone-only reviewer can open.
